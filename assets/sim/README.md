Weitere Marken können jederzeit ergänzt werden. Dazu im `app.js` einen neuen Produkteintrag mit einem eigenen Bildpfad wie `assets/sim/meine-marke.jpg` anlegen und das Bild anschließend hier hochladen.

Unterstützte Formate im Frontend: JPG, PNG, WEBP und SVG. Für beste Darstellung eignen sich Produktbilder mit freigestellter SIM/eSIM-Karte oder quadratischem Seitenverhältnis.
